# Развёртывание СтегоВизор 2.0 в закрытом контуре

## Требования

- Python 3.9 или новее.
- Tkinter для графического интерфейса (обычно входит в стандартную поставку Python; в некоторых Linux-дистрибутивах устанавливается отдельным системным пакетом).
- Пакеты из `requirements.txt`: numpy, scipy, Pillow, matplotlib, pypdf, customtkinter.

## Подготовка комплекта

На доверенной машине с доступом к репозиторию пакетов заранее подготовить совместимые wheel-файлы для целевой ОС, версии Python и архитектуры:

```bash
python -m pip download -r requirements.txt -d wheelhouse
```

Перенести весь каталог проекта вместе с `wheelhouse` в закрытый контур утверждённым носителем. До переноса проверить файлы антивирусными средствами, сверить контрольные суммы и выполнить процедуру допуска носителя, принятую на предприятии.

## Установка без интернета

Linux:

```bash
./install_offline.sh
```

Либо вручную:

```bash
python -m pip install --no-index --find-links ./wheelhouse -r requirements.txt
```

Windows:

```bat
python -m pip install --no-index --find-links wheelhouse -r requirements.txt
run_windows.bat
```

Установка должна выполняться из локального каталога пакетов. Если нужного wheel-файла нет, pip завершит установку ошибкой и не должен обращаться к индексу пакетов.

## Запуск и эксплуатация

```bash
python main.py                         # графический интерфейс
python main.py analyze ./incoming -r -o ./reports --db
python main.py sanitize ./incoming/doc.pdf -o ./clean/doc.pdf
python main.py pdf-extract ./incoming/doc.pdf -o ./extracted
python main.py monitor ./incoming --quarantine ./quarantine --report-dir ./reports
python run_tests.py                    # автономная проверка
```

Приложение не открывает браузер, не использует внешние веб-сервисы и не отправляет файлы за пределы машины/закрытого контура. Для дополнительного контроля можно ограничить исходящие соединения средствами ОС и сетевого экрана предприятия. Такой контроль рекомендуется включать в профиль базовой настройки рабочей станции.

Современное оформление интерфейса использует `customtkinter`. Если пакет не установлен, автоматически запускается классический Tkinter-интерфейс с тем же набором операций.

## Ограничения форматов

- PNG/APNG: структурный и статистический стегоанализ; санитизация PNG.
- JPEG/BMP/TIFF/WEBP/GIF: статистический анализ декодированных пикселей. Для GIF анализируется кадр, предоставляемый декодером Pillow.
- PDF: глубокий статический анализ структуры и всех достижимых объектов, включая JavaScript и действия, вложения, изображения, скрытый текст, метаданные и подписи. Содержимое документа не исполняется, внешние приложения не запускаются, сетевые обращения отсутствуют.
- PDF CDR: очищенная копия пересобирается локально; удаляются активное содержимое, вложения, формы, аннотации, ссылки, подписи, метаданные и неиспользуемые объекты, выполняется перекодирование изображений. Inline-изображения в потоках содержимого не перекодируются. Результат повторно проверяется встроенным анализатором.
- Зашифрованные PDF: используется пустой пароль или пароль, переданный через `--password` (в GUI — поле «Пароль PDF»). Пароль не записывается в конфигурацию, отчёты и журнал.
- Санитизация JPEG/BMP/TIFF/WEBP/GIF в этой версии не реализована.
